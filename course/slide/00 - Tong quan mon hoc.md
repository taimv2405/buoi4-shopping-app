# Chương 0. Tổng quan môn học — IE307 Công nghệ lập trình đa nền tảng cho ứng dụng di động

> Nguồn: `00 - Abstract.pdf` (10 slide) + `00 - Lecturer.pdf` (1 slide). ISE, UIT.

## Giảng viên
- **ThS. Phạm Nhật Duy** — email: `duypn@uit.edu.vn`
- Hướng nghiên cứu: Mobile Security, Web Security, Security for AI
- Đơn vị: Khoa học và Kỹ thuật Thông tin, Bộ môn Thiết bị di động và Công nghệ Web
- Phòng làm việc: E10.6 (Tầng 10, Tòa E, UIT)

## 1.1. Mục tiêu
- **Kiến thức nền tảng**: hiểu và nhớ kiến thức nền tảng về lập trình ứng dụng di động đa nền tảng với React Native (thành phần giao diện cơ bản, bố cục, điều hướng…).
- **Các kỹ thuật chính**: quản lý trạng thái, quản lý dữ liệu và xử lý biểu mẫu, API, xác thực người dùng, đa ngôn ngữ, module gốc, v.v.
- **Phát triển ứng dụng / Đề tài nghiên cứu**: phân tích, áp dụng kiến trúc đa nền tảng để xây dựng ứng dụng minh họa, dự án thực tế hoặc đề tài NCKH.

## 1.2. Chương trình
1. Giới thiệu môn học
2. Giao diện và các thành phần chính trong React Native
3. Giao diện nâng cao và điều hướng trong React Native
4. Điều hướng nâng cao và Làm việc với API
5. Quản lý trạng thái trong React Native
6. Xây dựng ứng dụng thương mại điện tử di động
7. Localization, Local Storage và Deployment
8. React Native CLI
9. Mã gốc và module gốc
